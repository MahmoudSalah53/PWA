يحتوي على Siri-style animations، LiveKit integration، RPC methods، وكل المزايا الموجودة في VoiceAgent.tsx!

📋 كيف تستخدمه:

  1. اضغط على الزر الدائري في أسفل يمين الشاشة
  2. انتظر حتى يتصل (سيظهر أنيميشن Siri)
  3. تكلم معه: "ابحث عن ايفون" أو "روح للصفحة الرئيسية"
  4. اضغط كليك يمين على الزر لإظهار أزرار الاختبار
  5. راقب الأنيميشنز تتحرك مع الصوت!

🎯 Events

الـ Web Component يرسل Events يمكنك الاستماع لها:

  • connected - عند الاتصال بنجاح
  • disconnected - عند قطع الاتصال
  • navigate - عند طلب التنقل (يحتوي على route)
  • connection-error - عند حدوث خطأ

⚙️ Properties

يمكنك تخصيص الإعدادات:

  • backend-url - رابط الـ Backend API
  • livekit-url - رابط LiveKit Server
  • token-endpoint - endpoint للحصول على Token
  • show-test-buttons - إظهار أزرار الاختبار
